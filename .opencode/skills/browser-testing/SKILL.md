# Browser Testing

Use the Playwright MCP tools when testing web applications.

## Workflow

1. Open the application.
2. Test the requested functionality.
3. Check for console errors.
4. Check for network errors.
5. Verify the UI behavior.
6. Take screenshots when useful.
7. Report problems with reproduction steps.

Use Playwright MCP rather than guessing browser behavior.
